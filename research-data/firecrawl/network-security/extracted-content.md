# Network Security - Firecrawl Extraction

## Source: Cloudflare - What is SASE?
URL: https://www.cloudflare.com/learning/access-management/what-is-sase/

### Key Concepts
- **SASE (Secure Access Service Edge)**: Combines networking and security functions into a single cloud-delivered service model
- **Zero Trust**: Never trust, always verify - identity-based access
- **SSE (Security Service Edge)**: Cloud-centric security (CASB, SWG, ZTNA)
- **Components**: SD-WAN, FWaaS, ZTNA, CASB, SWG
- **Benefits**: Reduced latency, simplified architecture, consistent policy

## Source: Palo Alto Networks - SASE vs SSE
URL: https://www.paloaltonetworks.com/cyberpedia/sase-vs-sse

### Key Concepts
- **SASE**: Networking + Security convergence
- **SSE**: Security-only subset (CASB, SWG, ZTNA)
- **Strata Platform**: Hardware/software firewalls, Strata Cloud Manager
- **Prisma SASE**: AI-powered, cloud-delivered

## Source: CrowdStrike - Zero Trust vs SASE
URL: https://www.crowdstrike.com/en-us/cybersecurity-101/zero-trust-security/zero-trust-vs-sase/
