# Identity Access - Firecrawl Extraction

## Source: Okta - Identity and Access Management
URL: https://www.okta.com/solutions/iam-identity-and-access-management/

### Key Concepts
- **IAM**: Codifying users, groups, and resource access in software systems
- **Workforce Identity**: SSO, adaptive MFA, lifecycle management, universal directory
- **Customer Identity**: Authentication, authorization, user management for applications
- **Identity Governance**: Access certification, entitlement management, risk-based access

## Source: CyberArk - Privileged Access Management
URL: https://www.cyberark.com/what-is/privileged-access-management/

### Key Concepts
- **PAM**: Secure, manage, and monitor privileged access
- **Session Management**: Recording, monitoring, isolation of privileged sessions
- **Credential Management**: Vault, rotation, injection for secrets
- **Endpoint Privilege Manager**: Least privilege for endpoints

## Source: Okta vs CyberArk Comparison
URL: https://nhimg.org/articles/okta-vs-cyberark-identity-governance-trade-offs-for-iam-teams/

### Key Concepts
- **Okta**: Automating provisioning/deprovisioning, workforce identity
- **CyberArk**: Governing entitlements, approvals, privileged access
- **Hybrid Approach**: Okta for workforce IAM, CyberArk for PAM
